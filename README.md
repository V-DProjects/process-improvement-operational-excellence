# Process Improvement & Operational Excellence  
*From over 40 minutes of manual preparation to a fully automated process completed in under 5 seconds.*


## Project Overview

### Business Context

As part of the Real-Time Operations team supporting a project for Booking.com, reporting analysts were required to manually prepare operational data exported from QlikView before analysis could begin.

The preparation process involved:

- Formatting multiple columns
- Removing unnecessary information
- Adjusting spreadsheet structures
- Standardizing data for reporting requirements

This repetitive process was performed daily and was prone to human error, inconsistencies, and avoidable delays.



## Objective

Automate and standardize the daily reporting preparation process using Excel VBA, minimizing manual intervention and ensuring data was analysis-ready almost immediately.



## The Problem: Before Automation

### Original Workflow

1. Export data from QlikView
2. Retrieve the daily operational report
3. Manually format numerous columns
4. Remove unnecessary columns and data
5. Verify spreadsheet structure
6. Prepare the final file for analysis

### Challenges Identified

- Time-consuming and repetitive daily process
- Risk of manual formatting errors
- Inconsistent outputs between analysts
- Delayed access to actionable insights
- Valuable analyst time spent on administration instead of analysis


## The Solution: Excel Macro Automation

To eliminate manual preparation work, I developed an Excel VBA macro that automated all repetitive spreadsheet processing tasks.

### New Workflow

1. Export the daily data from QlikView
2. Run the Excel macro

The macro automatically:

- Applies all required formatting
- Removes unnecessary columns
- Standardizes the spreadsheet structure
- Delivers an analysis-ready file

### Result

- Fully prepared report generated in less than 5 seconds
- No manual formatting required
- No manual column deletion required
- Consistent output every time

**Key Improvement:** The solution leveraged existing reporting and data extraction processes without requiring changes to operational systems.

## Project Conclusion

The implementation of an Excel VBA macro transformed a repetitive and time-intensive reporting preparation process into a fast, reliable, and standardized workflow.

By automating formatting activities and removing unnecessary data, preparation time was reduced from approximately 40 minutes to under 5 seconds. The solution significantly reduced manual handling errors and enabled analysts within the Real-Time Operations team to focus on higher-value analytical activities.

This project demonstrates how practical automation and process improvement initiatives can generate measurable operational benefits without requiring significant changes to existing systems or business processes.
